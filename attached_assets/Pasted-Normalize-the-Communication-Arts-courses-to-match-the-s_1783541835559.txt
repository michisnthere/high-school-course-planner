Normalize the Communication Arts courses to match the standardized `choices` schema used elsewhere in the catalog.

### Scope

Modify **only** the Communication Arts division. Do not change any other divisions, departments, Prisma schema, importer, or validation logic.

### Goal

Many Communication Arts courses currently exist as two separate courses, one College Prep and one Accelerated, even though they represent the same course.

These should become **one course** with two choices.

### Merge Rules

When two Communication Arts courses:

* have the same title,
* have the same description,
* have identical prerequisites,
* ## but differ by:

  * "creditType"
  * "gpaWaiverOption"
  * "credits"
  * "isOnline"
  * offerings": [...] -- specifically courseCode

merge them into a single course.

The merged course should contain:

* one title
* one description
* one notes array
* one sourceReference
* one fulfillsRequirements array
* one attributes object
* one division
* one department

and a `choices` array.

Example:

```json
{
  "choices": [
    {
      "name": "College Prep",
      "creditType": "College Prep",
      "gpaWaiverOption": true,
      "credits": 1.0,
      "isOnline": false,
      "offerings": [...]
    },
    {
      "name": "Accelerated",
      "creditType": "Accelerated",
      "gpaWaiverOption": false,
      "credits": 1.0,
      "isOnline": false,
      "offerings": [...]
    }
  ]
}
```

The offerings should remain inside each choice, matching the current schema used for Music, Science, and Social Studies.

### Do NOT merge

Do not merge courses if:

* prerequisites differ
* descriptions differ in a meaningful way
* they represent genuinely different courses

### Validation

After completion:

* report every merged pair
* verify that no course codes were lost
* verify that no descriptions or notes were lost
* verify that every merged course still passes the JSON schema
* do not modify any other division
