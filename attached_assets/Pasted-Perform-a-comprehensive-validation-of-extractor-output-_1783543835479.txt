### Catalog structure

* every course belongs to exactly one division
* every course belongs to exactly one department
* every department belongs to exactly one division
* no orphan departments
* no orphan divisions

### Course integrity

* every course has

  * title
  * description
  * sourceReference
  * fulfillsRequirements
  * attributes

* every course uses exactly one of:

  * `offerings`
  * `choices`

Never both.

### Choices

For every course with choices:

* every choice contains all required fields
* duplicate courseCodes are allowed across different choices
* duplicate courseCodes within the same choice do not exist

### Offerings

Verify every offering contains:

* courseCode
* semesterLabel
* duration
* gradeLevels
* prerequisites

Verify:

* semester labels are valid
* durations are normalized
* grade levels are valid

### Graduation requirements

Verify:

* every fulfillsRequirements entry references an existing GraduationRequirement name
* there are no unknown requirement names
* there are no spelling mismatches
* there are no duplicate requirement names within a course

### Attributes

Verify every attributes object uses the expected schema.

Report any missing or unexpected keys.

### Duplicate detection

* duplicate course titles
* duplicate importKeys
* duplicate courseCodes within the same choice
* duplicate GraduationRequirement names

* every Communication Arts course fulfills the English requirement

### Summary

* total divisions

* total graduation requirements
