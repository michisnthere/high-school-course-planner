Normalize the extracted JSON according to the following schema rules. Do not modify course content, descriptions, prerequisites, course codes, or offerings unless required by these rules.

### 1. Remove unnecessary `choices`

Only include a `choices` array when a course has multiple student-selectable versions (for example: Regular vs Online, Early Bird vs Regular, College Prep vs Accelerated, Dual Credit vs Regular).

If a course has only one version, remove the `choices` array entirely and move its data directly onto the course.

The course should contain:

* offerings
* creditType
* credits
* gpaWaiverOption

There should not be a single "Regular" choice wrapping the only version of the course.

---

### 2. Courses with multiple versions

If multiple enrollment options exist, keep the `choices` array.

Each choice must be a complete object containing:

* name
* isOnline
* creditType
* credits
* gpaWaiverOption
* offerings

Do not rely on inheritance from the parent course.

---

### 3. Remove top-level `isOnline`

Never store `isOnline` on the parent course.

If choices exist, store `isOnline` on each choice.

If no choices exist, omit `isOnline` completely.

---

### 4. Remove redundant notes

Delete notes that merely describe an enrollment option already represented by a choice (such as "Early Bird option available").

Retain notes that contain unique information not represented elsewhere.

---

### 5. Normalize arrays

Always use arrays for:

* notes
* prerequisites

Never use null.

---

### 6. Normalize durations

Allowed values:

* Full Year
* One Semester

---

### 7. Normalize semester labels

Allowed values:

* Semester 1
* Semester 2

---

### 8. Normalize grade levels

Always store gradeLevels as sorted ascending integer arrays.

---

### 9. Remove duplicate prerequisite and corequisite entries.

---
